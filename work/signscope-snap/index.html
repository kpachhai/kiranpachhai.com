SignScope Snap

MetaMask Snap with insight into Hedera transactionsgithub.com/kpachhai/signscope-snap

Problem

In MetaMask, SignScope shows what a Hedera transaction contains before it is signed.github.com/kpachhai/signscope-snap/blob/main/packages/snap/snap.manifest.json

Approach

A MetaMask Snap with a transaction-insight handler for Hedera mainnet, testnet and previewnet. It resolves sender and recipient to Hedera account IDs through the mirror node, decodes HTS token calls with a standard token ABI, and decodes other contract calls with the verified ABI from a Sourcify server, HashScan's by default.github.com/kpachhai/signscope-snap/blob/main/packages/snap/src/index.tsx

Methods

Each transaction is checked against the user's preferences: an allow list of contracts that skip the checks, a ban list of contracts to block, an HBAR amount that triggers a warning, and an option to interact with verified contracts only. With an API key set, an LLM adds a plain-language safety assessment of a call to a verified contract.github.com/kpachhai/signscope-snap/blob/main/packages/snap/src/index.tsx

Outcome

Version 0.1.0 of the Snap, with a home page in MetaMask for its settings.github.com/kpachhai/signscope-snap/blob/main/packages/snap/snap.manifest.json
